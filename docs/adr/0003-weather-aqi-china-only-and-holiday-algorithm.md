# ADR 0003：天气仅国标 AQI，节日日期用算法

- 状态：Accepted
- 日期：2026-07-21
- 决策者：产品（用户）+ 实现方
- 关联：Info 时间卡 / 天气卡信息密度补强

## 背景

时间卡与天气卡主区信息偏稀。产品决定：

1. 时间卡增加当前节气与下一大陆法定节日倒计时；
2. 天气契约扩展湿度与 AQI，UI 展示今日高低温、湿度、AQI。

需要固定两处易腐决策：AQI 口径，以及节日日期从哪来。

## 决策

### 1. AQI 仅国标（China AQI）

- Info 响应字段 `aqi` 语义为 **China AQI（HJ 633）**。
- 解析路径仅服务中国城市（weathercn）；不将美标 AQI 数字写入该字段，也不套国标六档色。
- 无法提供国标值时字段省略，前端单项隐藏。

### 2. 法定节日当天用算法，不用年表

- 锚点是 **Statutory Holiday**（节日当天），不是放假安排。
- 元旦 / 劳动节 / 国庆：固定公历日。
- 春节 / 端午 / 中秋：由现有农历换算反推公历日。
- 清明：取该年节气「清明」的本地日历日。
- 不维护国务院通知多年表；不跟踪调休与补班。

### 3. 时间卡底部展示

- 底部视觉以节日倒计时替换时区文案；时区仍参与计算与 `data-timezone`。

## 后果

- 正面：零配置、可离线、与中文首页预期一致；AQI 不会因口径混用误导。
- 负面：极少年份农历/节气近似与官方日历差一天时，倒计时可能偏一天；须接受「节日当天」而非「放假第一天」的产品语义。
- 后续若要自定义纪念日或放假安排，另开配置模型，不塞进本 ADR 的默认算法。
